# Simran's Scrapbook

The portfolio of **Simran Kaur Bedi**, Frontend Engineer in Nagpur, India.

Walk through a hand-drawn notebook world with Vinie the beagle. Each place shows a part of Simran's work, and Vinie changes outfit in every one: Nagpur, the Tadoba jungle, space, the city, a stray-dog street, a workshop and the post office. The walk loops forever in both directions.

Prefer plain text? Press **Read as a page** in the top corner.

## Run it locally

It is a single static page with no build step.

```bash
npx http-server@14.1.1 . -p 3002
```

Then open http://localhost:3002.

## Deploy

Any static host works (Vercel, Netlify or GitHub Pages). Serve `index.html` from the repository root.

## Built with

- [three.js](https://threejs.org/) for the paper diorama, with every doodle drawn in code on a canvas
- Google Fonts: Gochi Hand, Kalam, Shantell Sans and Nunito

The paper-world idea was inspired by [Mr. Panda's portfolio](https://www.mr-pandas-psychologically-safe-portfolio.com/).
